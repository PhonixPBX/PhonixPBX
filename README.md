AskoziaPBX NG
=============

A revival of AskoziaPBX on Alpine Linux, Python (FastAPI), SQLite and Asterisk 22,
with bootable images for Raspberry Pi (arm64), amd64 and x86.

- Specification: [docs/SPEC.md](docs/SPEC.md)
- The original 2007–2011 tree (T2 SDE, PHP webgui) is preserved in [legacy/](legacy/) for reference.
