Status

Übersicht

Status → Übersicht ist die Startseite der Weboberfläche. Sie erreichen sie nach der Anmeldung und mit einem Klick auf das PhonixPBX-Logo. Sie zeigt den Zustand des ganzen Systems auf einen Blick.

Hinweise

Oben auf der Seite erscheinen gegebenenfalls Hinweise, die Ihre Aufmerksamkeit brauchen:

  • Sie verwenden noch das initiale Administratorpasswort. Das Passwort von der Konsole ist noch in Gebrauch. Folgen Sie dem Link Ändern Sie es jetzt und wählen Sie ein eigenes, siehe Passwort ändern.
  • Die Weboberfläche verwendet ein selbstsigniertes Zertifikat. Browser warnen vor diesem Zertifikat. Unter Erweitert → Zertifikat beziehen Sie ein Zertifikat von Let’s Encrypt oder laden Ihr eigenes hoch.
  • PhonixPBX X ist verfügbar. System aktualisieren. Eine Suche nach Updates hat eine neuere Version gefunden. Der Link führt zu System → Firmware. Der Hinweis verschwindet, sobald diese Version installiert ist.
  • Die AskoziaPBX-Konfiguration (config.xml) von der Boot-Partition wurde beim ersten Start importiert. Darunter zeigt der Importbericht, was übernommen, übersprungen oder verworfen wurde, siehe Umstieg von AskoziaPBX. Prüfen Sie den Bericht und die importierten Einstellungen und klicken Sie dann auf Ausblenden.

Kennzahlen

Die vier Karten in der ersten Reihe:

KarteZeigt

CPU-LastDurchschnittliche Last der letzten Minute, darunter die Mittelwerte über 1, 5 und 15 Minuten und die Zahl der CPUs. Liegt der Wert dauerhaft über der Zahl der CPUs, ist das System überlastet.
ArbeitsspeicherAnteil des belegten Arbeitsspeichers, als Balken und in absoluten Zahlen.

Telefonie

Die Karte Telefonie zeigt den Zustand von Asterisk, dem Telefonie-Kern von PhonixPBX, und wird alle 10 Sekunden aktualisiert:

  • die Asterisk-Version, die Zahl der Aktiven Kanäle und wie viele SIP-Telefone von allen SIP-Telefonen registriert sind (Registrierte SIP-Telefone),
  • die Provider mit ihrem Registrierungs- bzw. Erreichbarkeitszustand.

Antwortet Asterisk nicht, zeigt die Karte Asterisk ist nicht erreichbar mit der Fehlermeldung. Der Link Details führt zu Gespräche & Registrierungen, wo zusätzlich jedes Telefon und die aktiven Gespräche aufgeführt sind.

Graphen

Unten zeigen zwei kleine Graphen die CPU-Auslastung in Prozent und den Netzwerkverkehr der letzten Minuten. Sie werden nur gefüllt, solange die Seite geöffnet ist. Größere Fassungen finden Sie unter Status → Graphen.
