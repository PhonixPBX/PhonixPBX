Call Groups

A call group rings several phones for one call, either all at the same time or one after another. Use it for a team number, a hotline or a reception that several people answer. Call groups are managed under Dialplan → Call Groups.

Changes take effect after you apply them, see Applying changes.

Call group list

Click Call group above the list to add one. The list shows the Number (or – for groups without a number), the Name (with a public badge when the group is reachable from outside), the Members and the Strategy (ring all or one after another). The buttons at the end of each row edit and delete the group. Deleting a group also removes the incoming routes and IVR keys that led to it.

Calls that nobody answers go to the voicemail box of the first member (the first phone of a contained call group), if that phone has voicemail enabled; otherwise the call ends. The missed call e-mail of the first member is used for the group as well. Disabled phones are skipped.

Call groups in call groups

A member can also be another call group. It stands for all of its phones, so you keep each team in one group and build larger groups from them, for example Support = Support L1 + Support L2. A change to Support L1 then applies to Support as well.

  • With Ring all at once, the phones of all contained groups ring together.
  • With One after another, a contained group is one step: all its phones ring at the same time, then the next member follows. Its own ring strategy does not matter here.
  • A phone that is in several of the groups rings only once, at its first place.
  • A group cannot contain itself, directly or through another group. Such groups are not offered in Members, and saving is refused.
  • Deleting a call group removes it from the groups that contain it.

Set up a team number

  1. Make sure every team member has a phone.
  2. Click Call group, enter a Name and a Number, and select the Members.
  3. To have unanswered calls recorded, put a phone with voicemail first, and set a Ring time so the call reaches the mailbox.
  4. Click Create and apply the changes.
  5. To route an outside number to the team, add an incoming route with the group as destination.

Instead of a call group, you can also add several incoming routes with the same number and different phones on a provider; those phones then ring at the same time.
