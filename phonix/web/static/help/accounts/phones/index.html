Accounts

Phones

A phone is an internal number that rings a device. Every desk phone, softphone or mobile app that registers with the PBX needs its own phone account, and an external phone lets an internal number ring a mobile or another system. Phones are managed under Accounts → Phones.

Changes to phones take effect after you apply them, see Applying changes.

Phone types

TypeUse it for
SIP phoneDesk phones, softphones and apps that speak SIP. This is the usual choice.
IAX phoneDevices or other Asterisk systems that speak IAX2 (port 4569 UDP).
External phoneAn internal number that forwards to a number outside the PBX: a mobile number dialled through a provider, or a SIP or IAX address (user@host). It has no password and does not register.

The type is chosen with the buttons SIP phone, IAX phone and External phone above the list and cannot be changed later. To change it, create a new phone and delete the old one.

Phone list

The list shows every phone, sorted by number:

ColumnMeaning
ExtensionThe internal number. Click it to edit the phone.
NameThe caller ID name.
TypeSIP, IAX or External.
StatusFor SIP phones registered (with the address of the device) or not registered; for IAX phones the peer state; for external phones the number or address they forward to. The column refreshes every 15 seconds. Asterisk down means the telephony service is not running.
VoicemailA mail icon when the phone has a voicemail box.
DescriptionYour note.

The buttons at the end of each row edit, disable/enable and delete the phone. A disabled phone keeps its settings but is left out of the configuration: it cannot register and cannot be called. Deleting a phone also removes the incoming routes and IVR keys that pointed to it or to its voicemail box; the fixed destinations of IVR menus and business hours that pointed to it fall back to Hang up.

The currently registered devices and active calls are also shown under Status → Calls & Registrations.

Add a SIP phone

  1. Open Accounts → Phones and click SIP phone.
  2. Keep the suggested Number or enter your own, and type the Caller ID name.
  3. Copy the generated Password (eye button) before you save.
  4. Optionally switch on Enable voicemail on the Voicemail & notifications tab.
  5. Click Create phone, then apply the changes.
  6. Configure the device as described below.

Configure a SIP phone or softphone

Enter these values in the account settings of the phone or softphone:

Setting on the deviceValue
Server, registrar, domain or proxyThe IP address (or host name) of the PBX.
User name, user ID, authentication userThe phone’s Number, for example 101.
PasswordThe phone’s Password.
Display nameAnything; the PBX uses the Caller ID name.
Transport and portUDP on port 5060. TCP (also port 5060) and TLS (port 5061) work when they are enabled under Advanced → SIP.
Voicemail number000086

After the device registers, its status in the list changes to registered. Dial 00003246 (the echo test) to check audio in both directions.

If the phone does not register, check the user name and password first, then the firewall: the SIP port may be limited to certain networks under Advanced → Firewall, and repeated wrong passwords can get a device’s address banned for a while.

IAX phones are set up the same way: server = the PBX address, user name = the number, the password, port 4569 UDP.
