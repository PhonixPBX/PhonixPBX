System

The System menu holds the settings of the appliance itself rather than of the telephone system: host name, time and network, the data partition, firmware updates, backups, the factory reset and reboot.

  • General Setup: host name, domain, time zone, time servers, tone zone, prompt language, mDNS and SSH access.
  • Network: LAN address (DHCP or static), DNS servers, IPv6 and the NAT settings for SIP.
  • Storage: how full the data partition is and what uses the space.
  • Firmware: the installed version, update checks and installing signed update bundles.
  • Backup/Restore: backups of the configuration, restore, and the import and export of AskoziaPBX config.xml files.
  • Factory Defaults: erase all data and start over.
  • Reboot: restart or shut down the system.

Changes on General Setup and Network take effect only after you apply them, see Applying changes.

In a container (LXC/Incus system container or OCI image), some of these pages behave differently: the network, the host name of the container and the clock belong to the container host, and updates work differently. Each page says what applies.

General Setup
Host name, domain, time zone, time servers, tones, prompt language, mDNS and SSH access.
Network
LAN address by DHCP or static, DNS servers, IPv6 and the NAT settings for SIP.
Storage
Usage of the data partition and the space taken by configuration, media, backups and voicemail.
Firmware
Installed version, checking for updates and installing signed update bundles, with A/B slots and rollback.
Backup/Restore
Create, download and restore backups, and import or export AskoziaPBX config.xml files.
Factory Defaults
Erase all configuration and data and start again as on the first boot.
Reboot
Restart or shut down the system.
