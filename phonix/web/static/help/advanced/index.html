Advanced

The Advanced menu contains the technical settings of the PBX: SIP, IAX and RTP parameters, access for external software over the Asterisk Manager Interface, the firewall, the TLS certificate, the administrators of the web interface, API tokens and options of the web interface itself.

The defaults suit most installations. Change these settings only when you know why, and keep a backup before larger changes. Telephony and firewall settings become active after you apply them, see Applying changes.

SIP
SIP ports and transports (UDP, TCP, TLS), SRTP media encryption and registration timers.
IAX
IAX2 port, firewall access and jitter buffer.
RTP
The UDP port range for call audio and video.
Manager (AMI)
Users for the Asterisk Manager Interface, with permitted networks and permissions.
Firewall
Packet filter, networks allowed to manage the PBX and to use SIP/IAX, and blocking after failed logins.
Certificate
The TLS certificate of the web interface and SIP over TLS: self-signed, uploaded, or from Let's Encrypt/ACME.
Administrators
User accounts for the web interface.
API tokens
Bearer tokens for the REST API and MCP: read-only or read-write, expiry, permission to place calls.
GUI Options
Automatic logout of the web interface, language and theme.
