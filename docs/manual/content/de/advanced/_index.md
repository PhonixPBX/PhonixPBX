Das Menü *Erweitert* enthält die technischen Einstellungen der TK-Anlage: SIP-, IAX- und RTP-Parameter, den Zugang für externe Software über das Asterisk Manager Interface, die Firewall, das TLS-Zertifikat, die Administratoren der Weboberfläche, API-Tokens und Optionen der Weboberfläche selbst.

Die Standardwerte passen für die meisten Installationen. Ändern Sie diese Einstellungen nur, wenn Sie wissen, warum, und erstellen Sie vor größeren Änderungen ein [Backup]({{< relref "/system/backup.md" >}}). Telefonie- und Firewall-Einstellungen werden wirksam, wenn Sie sie übernehmen, siehe [Änderungen übernehmen]({{< relref "/getting-started/_index.md#apply" >}}).
